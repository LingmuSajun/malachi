# docs/ops

運用手順・KPI・障害対応・モニタリングのドキュメント。

## ファイル構成(推奨)

```
docs/ops/
├── README.md
├── kpi.md                   # KPI 定義(MAU/課金率/LTV/チャーン等)
├── runbook.md               # 障害対応 Runbook
├── monitoring.md            # 監視項目・アラート設定
├── customer-support.md      # CS フロー(クレーム対応、危機対応)
└── deploy.md                # デプロイ手順
```

## KPI(MVP 段階で追跡推奨)

### ユーザー

- 友だち追加数
- アクティブユーザー数(WAU/MAU)
- ブロック率

### 収益

- 課金転換率(無料→有料)
- ARPU、MRR
- チャーン率
- LTV

### 体験

- 鑑定完了率
- 1セッションあたり鑑定回数
- リテンション(D1, D7, D30)

### 安全性

- 危機検知発動率
- セーフティ違反応答の割合(eval-report.md より)

## 障害対応(基本フロー)

1. 検知(モニタリングアラート / ユーザー報告)
2. 影響範囲の特定
3. 一時対応(必要なら機能停止)
4. 原因究明
5. 恒久対応
6. ポストモーテム作成
