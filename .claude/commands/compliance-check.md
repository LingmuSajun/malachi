# /compliance-check - 法令・倫理コンプライアンスチェック

LP コピー、メッセージ、機能仕様、UI 文言などを公開前にチェックする。

## チェック対象

以下のいずれか:

- LP / 広告クリエイティブ
- LINE 公式アカウントのプロフィール文・あいさつ文
- 利用規約・プライバシーポリシー・特商法表示
- マラキの新しい応答パターン
- メールマガジン・プッシュ通知の文面
- 価格表示・料金プラン説明

## 動作

1. チェック対象のテキストをユーザーから受け取る

2. 必ず以下のスキルを参照:
   - `.claude/skills/divination-law/SKILL.md`(占い特有の法令)
   - `.claude/skills/malachi-voice/SKILL.md`(ブランド一貫性)

3. 必要に応じて `.claude/agents/compliance.md` の subagent を起動

4. 以下の観点で1項目ずつチェック:

### A. 法令面

- **景表法** — 「絶対」「100%」「必ず」「世界一」などの断定・優良誤認
- **特商法** — 価格表示、解約条件、事業者情報の明示
- **薬機法** — 健康・医療効果の暗示(「治る」「改善する」「効く」)
- **消費者契約法** — 不安を煽って契約させる、損害賠償条項の不当性
- **個人情報保護法** — 取得・利用目的の明示、第三者提供の同意

### B. 倫理・ブランド面

- **第三者中傷** — ユーザーの恋人や家族を断罪する表現
- **不安喚起** — 「呪われている」「最悪の運命」など
- **ジェンダー** — 性別決め打ち、ステレオタイプ
- **児童保護** — 18歳未満が読む可能性、誘発的な表現
- **マラキらしさ** — 軽薄でないか、安っぽくないか

### C. プラットフォーム規約

- **LINE 利用規約** — メッセージング規約、広告ガイドライン
- **App Store / Google Play** — 占いコンテンツの審査基準

## 出力フォーマット

```
## チェック対象
(該当テキスト)

## 判定: 🟢合格 / 🟡要修正 / 🔴禁止

## 詳細
- [景表法] OK
- [薬機法] ⚠️「効果あり」が暗示されている → 「個人の感想」と明記推奨
- [ブランド] OK

## 修正案
(具体的な書き換え案)

## 記録先
docs/legal/compliance-log.md に追記
```

## 重要

判断に迷うケースでは、必ず「より慎重な側」を選ぶ。
法的グレーは「やらない」を選ぶ。

最終的な法務判断は弁護士に確認すること。Claude のチェックは一次フィルター。
