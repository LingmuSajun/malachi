# Skill: divination-law

日本における占いビジネス特有の法令・規制の参照知識。

## このスキルを使うべき場面

- 利用規約・プライバシーポリシー作成時
- 特商法表示の作成・更新時
- LP・広告コピーの公開前チェック
- 価格・解約フロー設計時
- 新機能の法的リスク評価時
- compliance subagent が判断する時

## ⚠️ 重要な前提

**このスキルは弁護士の代替ではない**。
明らかに NG なものを止めるための一次フィルター。
重要案件は必ず弁護士に確認すること。

特に以下は専門家確認必須:

- 利用規約・プライバシーポリシーの最終版
- 高額プラン(月3,000円超)の課金フロー
- 行政処分・訴訟対応

## 占いビジネスに関わる主要法令

### 1. 景品表示法(景表法)

**目的**: 不当な表示で消費者を誤認させることを防ぐ。

#### 占いで NG な表現

- 「絶対に当たる」「100%的中」(優良誤認)
- 「業界NO.1」「日本一」(根拠不明な比較)
- 「永久無料」(条件付きの場合)
- 「効果保証」「結果に満足できなければ全額返金」(不当な保証)

#### OK な表現

- 「人気の占いサービス」(主観表現)
- 「鑑定実績○件」(実数の根拠あり)
- 「ユーザー満足度○%(2024年自社調べ、N=1,000)」(出典・サンプル明示)

#### 過去の事例(参考)

- 占いサービスでの優良誤認による措置命令事例が複数あり
- 消費者庁「景品表示法違反事例」を参照
- 「あなたの恋愛運が劇的に改善する」のような断定表現で問題化したケース

### 2. 特定商取引法(特商法)

**目的**: 通信販売・継続課金での消費者保護。

#### 必須表示項目

サブスクサービスの場合、以下を明確に表示する義務:

- **事業者名**(法人名・代表者名・所在地・電話番号)
- **販売価格**(税込・追加費用の有無)
- **支払時期・方法**(クレカ・LINE Pay 等)
- **サービス提供時期**(申込み後すぐに利用可能か等)
- **解約条件**(解約方法・解約手数料の有無)
- **動作環境**(必要な OS・LINE バージョン等)

#### サブスクの追加義務(2022年の法改正で強化)

- **「定期購入」であることの明示**(単発ではないことが分かる UI)
- **次回課金日・金額の事前通知**
- **解約導線の明確化**(複雑にしない)

「特商法表示」のページを LP / アプリ内に必ず設置。

### 3. 薬機法(医薬品医療機器等法)

**占いに関係ない**と思いがちだが、メンタル系訴求で要注意。

#### NG 表現(医療効果の暗示)

- 「うつが治る」「メンタルが改善する」
- 「ストレスに効く」「不安が消える」
- 「精神的な病気が良くなる」

#### OK 表現

- 「気持ちの整理になる」
- 「自分を見つめる時間に」
- 「考えるきっかけ」
- 「心の支え」(ただし 効果保証 にはならないように注意)

### 4. 消費者契約法

**目的**: 不利な契約から消費者を保護。

#### 占いで関わる典型的論点

- **不安をあおって契約させる** — 「呪われている、今すぐ除霊しないと不幸が続く」のような訴求
- **退会困難な仕組み** — 解約手続きを意図的に難しくする
- **損害賠償条項の不当性** — 「キャンセル料100%」のような不当条項
- **重要事項の不告知** — 自動更新・追加課金の条件を明示しない

過去に大きな問題となった例:

- 「霊感商法」による高額契約
- 退会困難なポイント制占いサイト
- 占い師の助言を口実とした追加課金

### 5. 個人情報保護法

#### 必須対応

- 取得時に **利用目的の明示**
- **第三者提供の同意**(API 連携、広告配信先など)
- **保有個人データの開示・削除請求への対応**
- **漏洩時の報告義務**(個人情報保護委員会への報告と本人通知)

#### Anthropic API への送信

ユーザーの相談内容を Claude API に送ることになる。
プライバシーポリシーで以下を明示:

- 「ユーザーの相談内容は AI(Anthropic 社の Claude)に送信され、応答生成に使用されます」
- 「Anthropic 社のデータ利用方針はこちら(リンク)」
- 「データは応答生成のみに使われ、AI モデルの学習には使用されません」(※ Anthropic API の仕様確認の上で記載)

### 6. 著作権法

#### 占いコンテンツでの注意

- タロットカードの**画像** — 1909年版ライダー・ウェイト・タロットはPD、再販版はNG
- 占い解釈の**文章** — 既存の占い書籍からの引用は要許諾
- カードの**配列・スプレッド** — 一般的なものは公知だが、独自の名前付きスプレッドは創作性あり

### 7. 児童保護関連

#### 18歳未満への対応

未成年が利用する可能性がある場合:

- 利用規約で年齢制限を明記
- 親権者の同意取得フロー(高額課金時は特に重要)
- 性的・恋愛的に過度な相談への対応方針

#### マラキでの方針

- 利用規約で「13歳以上、未成年は親権者同意必須」を明記
- 危機検知で18歳未満が示唆された場合の応答パターンを設計

### 8. プラットフォーム規約

#### LINE 利用規約

- 占いサービスでの過度な勧誘禁止
- ユーザー同意のない広告メッセージ禁止
- 第三者を貶める内容の禁止

#### App Store / Google Play(将来)

- 占いアプリの審査基準は変動するが、Apple は厳しい傾向
- 「絶対」「保証」系の表現は審査落ちリスク

## チェックリスト(機能・コピー公開前)

### LP・広告

- [ ] 「絶対」「100%」「必ず」を使っていない
- [ ] 競合との比較で根拠不明な優位主張をしていない
- [ ] 「効果保証」のような不当な保証を謳っていない
- [ ] 不安を煽る訴求(呪い、最悪、危険)をしていない
- [ ] 価格表示が正確(税込、追加費用の有無)
- [ ] 解約条件を明示している
- [ ] 体験談・口コミは実在のものか、架空なら明示

### 利用規約・特商法表示

- [ ] 事業者情報を完備
- [ ] 価格・支払方法・提供時期を明示
- [ ] 解約方法・手数料を明示
- [ ] 「定期購入」であることを明示
- [ ] 次回課金日の事前通知の仕組み
- [ ] 動作環境を明示

### プライバシーポリシー

- [ ] 取得情報の明示
- [ ] 利用目的の明示
- [ ] 第三者提供の有無と同意取得
- [ ] Anthropic API への送信について明記
- [ ] 開示・削除請求への対応窓口
- [ ] 漏洩時の対応方針

### マラキの応答

- [ ] 「絶対に〜になる」のような断定的予言をしていない
- [ ] 医療効果の暗示をしていない
- [ ] 第三者を断罪していない
- [ ] 不安を煽っていない
- [ ] 危機状態を専門家に繋いでいる

## 弁護士相談のタイミング

以下のタイミングで法務確認推奨:

1. **MVP 公開前** — 利用規約・特商法表示・プライバシーポリシー
2. **プラン変更時** — 価格改定、新プラン追加
3. **ユーザークレーム発生時** — 個別案件の対応
4. **広告キャンペーン前** — 大規模広告は表現の事前チェック
5. **行政からの照会時** — 即座に専門家へ

弁護士は IT・消費者法に詳しい人を選ぶこと。
顧問契約を検討する規模になったら、月数万円〜から相談可能。
