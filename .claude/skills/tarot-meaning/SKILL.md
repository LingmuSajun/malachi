# Skill: tarot-meaning

タロットカード(特に大アルカナ)の伝統的解釈と、Malachi 流の現代的再解釈の参照知識。

## このスキルを使うべき場面

- 新しいカードのデータを書く時(新カード追加、解釈の更新)
- ユーザーから「このカードはどういう意味?」と問われた時
- スプレッドの設計・実装時
- カードの組み合わせ(連続するカードの相互作用)を考える時

## 参照すべき詳細データ

完全な大アルカナ22枚のデータは:

- `packages/tarot/data/major-arcana.yaml`

このスキルでは概観・原則を扱う。

## 大アルカナの構造(覚え方)

22枚は3つの章に分けて理解できる(Marseille / Waite に共通の見方):

### 第1章: 0〜7 「外的世界の獲得」

愚者 → 魔術師 → 女教皇 → 女帝 → 皇帝 → 教皇 → 恋人 → 戦車

社会的な役割・関係性・選択を学ぶ段階。

### 第2章: 8〜14 「内的世界の探求」

力 → 隠者 → 運命の輪 → 正義 → 吊るされた男 → 死神 → 節制

自分の内側、潜在意識、変容を経験する段階。

### 第3章: 15〜21 「霊的世界の超越」

悪魔 → 塔 → 星 → 月 → 太陽 → 審判 → 世界

執着の自覚、崩壊、再生、完成へと至る段階。

## 正位置・逆位置の解釈原則

### 一般原則

- **正位置(upright)** = カードのエネルギーが順調に発現
- **逆位置(reversed)** = エネルギーが阻害、過剰、または内向

ただし「逆位置 = 悪い」ではない。
死神逆位置は「変化を恐れる」という別の課題を示す。

### 強いカード・弱いカードの区別はしない

Malachi では、すべてのカードに教えがあるとして扱う。
「凶兆」「悪いカード」という表現は使わない。

## カードの組み合わせ(コンビネーション)

複数枚スプレッドでは、カード同士の関係性が意味を補強する。

### 同じスート/系統の連続

- 大アルカナが3枚連続で出たら → 重要な人生の節目
- 同じ象徴(例: 死神 + 塔 + 審判)→ 大きな変容の時

### 矛盾するカードが並ぶ

- 「死神」と「世界」 → 終わりと完成、新しいサイクルへの移行
- 「悪魔」と「星」 → 束縛の中の希望

### スプレッド位置との相互作用

- 過去 / 現在 / 未来:時間軸での意味の変化
- 自分の気持ち / 相手の気持ち:対の構造

各カードの位置別解釈は yaml の `positions` セクション参照。

## Malachi 流の解釈原則

### 1. 否定的に響かせない

伝統的解釈で「凶兆」とされるカード(死神、塔、悪魔、月)も、
**成長・気づきの機会** として再フレーミングする。

例:

- 死神 → 「終わりではなく、変容の門」
- 塔 → 「偽りの構造の崩壊、その後に真実が見える」
- 悪魔 → 「自分自身が選んだ束縛、いつでも外せる」
- 月 → 「不安には根拠がある、直感が真実を察知している」

### 2. 30代女性の文脈に引きつける

すべての解釈は「30代女性が抱える悩み(恋愛・人間関係・自己実現)」に
直結させる。抽象論ではなく具体的な気づきに落とす。

### 3. 主体性を奪わない

カードが何を示しても、最終的な選択はユーザーに委ねる。
「カードは示した。選ぶのはあなただ」

### 4. 神秘性を保つ

伝統的解釈をそのまま教科書的に語らない。
カードの象徴を簡潔に示し、すぐに ユーザーの状況に引きつける。

✅ 「死神は終わりを告げるのではない。あなたが手放せずにいるその関係、本当はもう答えが出ているのではないか」

❌ 「死神のカードはユング心理学の死と再生のアーキタイプを表し、変容を意味します」

## 参考文献(伝統的解釈の出典)

- A.E. Waite "The Pictorial Key to the Tarot" (1910, パブリックドメイン)
  https://www.sacred-texts.com/tarot/pkt/
- Pamela Colman Smith による1909年の象徴的描画

これらは大アルカナ22枚の意味データ作成時の基礎資料となる。
ただし、Malachi 流の解釈は伝統に縛られず、現代の心理学的洞察も取り入れる。
